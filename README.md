# JAKE — Another Nightmare

An English-language, responsive birthday horror experience using HTML, CSS and vanilla JavaScript. No packages or build step.

## Deploy to Netlify
Upload this folder's contents to the root of a GitHub repository. In Netlify, import that repository. Leave the build command empty; publish directory: `.`. The included netlify.toml configures this automatically. Alternatively drag this folder into Netlify Drop.

## Local preview
Open index.html directly, or run `python3 -m http.server 8080` here and visit http://localhost:8080. Sharing works best on the deployed HTTPS site.

## Experience
- Original rural horror, supernatural bedroom and anonymous caller scenes, inspired by classic horror subgenres.
- Three interactive story dialogs with branching choices; Escape closes a dialog.
- Original, procedural ambient soundtrack made with Web Audio. Tap SOUNDTRACK to start or stop. No copyrighted recordings, no audio downloads, no autoplay.
- Motorcycle rev, playable birthday tape, candle ritual and native share/clipboard support.
- Reduced-motion preferences and manual motion pause; keyboard-accessible controls.

All artwork is original CSS/SVG. No movie posters, character likenesses, clips or movie scores are included. Optional Google Fonts require an internet connection; system fallbacks work offline. Edit text in index.html and the chapters object in script.js. Colors and layouts are in styles.css.
